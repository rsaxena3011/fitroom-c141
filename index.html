How FitRoom works

FitRoom is a product-page try-on. Your photo and the garment go to the Clothsy AI virtual try-on API (built on FabricVTON), which returns a realistic image of you wearing the garment. The fit verdict is separate from the image: it compares the garment’s stated chest measurement in your usual size against the standard for that size, so you know before you buy whether to take your usual size, size up, or size down. Fewer wrong sizes means fewer returns — that is the retail value.

Sample shoppers Ana and Dev are AI-generated adults, made for this demo. No real person’s photo is used without consent, and no photo of a minor is ever used. In demo mode the app shows pre-generated sample results, clearly labelled; run the included server with a Clothsy API key for live try-ons.
